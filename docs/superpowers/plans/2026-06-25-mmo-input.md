# mmo_input Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the `mmo_input` crate — a Bevy plugin that translates WoW-style keyboard/mouse and FFXIV-style gamepad input into a per-frame `MmoMovementState` component, with an optional `tnua` feature that drives a `TnuaBuiltinWalk` basis from that state.

**Architecture:** `bevy_enhanced_input` action entities are spawned as children of any entity carrying `MmoMovementContext`; a reactive system rebuilds them when `MmoBindings` (a serialisable resource) changes. A second system reads those action entities each frame in pull-style and writes `MmoMovementState`, applying `MmoMovementMask` before writing. The optional `tnua` feature exposes a generic system `drive_walk_basis<S>` that the game instantiates with its own `TnuaController` action-scheme type.

**Tech Stack:** Rust 2024 edition, Bevy 0.19, bevy_enhanced_input 0.26, bevy-tnua 0.32 (optional), bitflags 2, serde 1.

## Global Constraints

- Bevy: `0.19`, default-features = false
- bevy_enhanced_input: `0.26`
- bevy-tnua: `0.32`, optional, feature-gated behind `tnua`
- bitflags: `2`
- serde: `1`, features = ["derive"]
- Bevy `serialize` feature must be enabled so `KeyCode`, `MouseButton`, `GamepadButton` get `Serialize`/`Deserialize`
- All actions use `consume_input: false` — movement never blocks ability or UI systems
- All public types derive `Reflect`
- `MmoCameraOrientation` is expected from a future `mmo_camera` crate; all code that reads it uses `Option<&MmoCameraOrientation>` so the crate works without it
- Run `cargo check` and `cargo test` after every task before committing
- Crate lives at `crates/mmo_input/` in the workspace

use bevy::prelude::*;
use bitflags::bitflags;
use serde::{Deserialize, Serialize};

#[derive(Component, Reflect, Serialize, Deserialize, Default, Clone)]
#[reflect(Component)]
pub struct MmoMovementState {
    /// Camera-relative movement intent. X = strafe (right+), Y = forward (+).
    /// Keyboard: 0.0 or ±1.0. Gamepad left stick: analog ±1.0.
    pub move_intent: Vec2,
    /// Vertical movement intent for swimming/flying. +1 = up, -1 = down.
    pub vertical_intent: f32,
    /// Character yaw change this frame in radians.
    pub yaw_delta: f32,
    /// Raw camera orbit delta (radians). X = yaw, Y = pitch. For mmo_camera.
    pub camera_delta: Vec2,
    /// Jump binding fired this frame. Signal only.
    pub jump: bool,
    /// Sprint binding fired this frame. Signal only.
    pub sprint: bool,
    /// Auto-run toggled on.
    pub auto_run: bool,
    /// RMB held (kb/mouse) or gamepad active (always true for Gamepad source).
    pub is_mouse_look: bool,
    /// Which input device drove this frame.
    pub input_source: InputSource,
    /// Monotonic tick counter for netcode / prediction.
    pub tick: u64,
}

#[derive(Reflect, Serialize, Deserialize, Clone, Copy, Default, PartialEq, Eq, Debug)]
pub enum InputSource {
    #[default]
    KeyboardMouse,
    Gamepad,
}

bitflags! {
    #[derive(Component, Reflect, Serialize, Deserialize, Clone, Copy, Debug, PartialEq, Eq)]
    #[reflect(Component)]
    pub struct MmoMovementMask: u8 {
        /// Controls move_intent.
        const MOVEMENT = 0b0001;
        /// Controls yaw_delta only — camera_delta is never masked.
        const TURNING  = 0b0010;
        /// Controls jump and sprint signals.
        const JUMPING  = 0b0100;
        /// Controls vertical_intent.
        const VERTICAL = 0b1000;
        const ALL      = 0b1111;
    }
}

impl Default for MmoMovementMask {
    fn default() -> Self {
        Self::ALL
    }
}

use bevy::input::{gamepad::GamepadButton, keyboard::KeyCode, mouse::MouseButton};
use bevy::prelude::*;
use bevy_enhanced_input::prelude::*;
use serde::{Deserialize, Serialize};

/// Serde-friendly wrapper over a rebindable physical input.
/// Gamepad axes (left/right stick) are hardcoded and not represented here.
#[derive(Clone, Debug, Serialize, Deserialize, PartialEq, Reflect)]
pub enum UserBinding {
    Key(KeyCode),
    Mouse(MouseButton),
    Gamepad(GamepadButton),
}

impl UserBinding {
    pub fn to_bevy_binding(&self) -> Binding {
        match self {
            UserBinding::Key(k) => Binding::from(*k),
            UserBinding::Mouse(m) => Binding::from(*m),
            UserBinding::Gamepad(b) => Binding::from(*b),
        }
    }
}

#[derive(Resource, Reflect, Serialize, Deserialize, Clone)]
pub struct MmoBindings {
    // Keyboard / mouse (WoW-style defaults)
    pub move_forward:  Vec<UserBinding>,
    pub move_backward: Vec<UserBinding>,
    pub turn_left:     Vec<UserBinding>,
    pub turn_right:    Vec<UserBinding>,
    pub strafe_left:   Vec<UserBinding>,
    pub strafe_right:  Vec<UserBinding>,
    pub jump:          Vec<UserBinding>,
    pub mouse_look:    Vec<UserBinding>,
    pub left_mouse:    Vec<UserBinding>,
    pub auto_run:      Vec<UserBinding>,
    /// Empty by default (WoW has no keyboard sprint). Game can assign e.g. Shift.
    pub sprint:        Vec<UserBinding>,

    // Gamepad (FFXIV-style defaults)
    pub gamepad_jump:   Vec<UserBinding>,
    pub gamepad_sprint: Vec<UserBinding>,

    // Camera (consumed by mmo_camera crate)
    pub zoom_in:    Vec<UserBinding>,
    pub zoom_out:   Vec<UserBinding>,
    pub zoom_speed: f32,

    // Sensitivity
    pub mouse_sensitivity:   f32,
    pub gamepad_sensitivity: f32,
    pub kb_turn_speed:       f32,
}

impl Default for MmoBindings {
    fn default() -> Self {
        use bevy::input::gamepad::GamepadButton as Gp;
        use KeyCode::*;
        use MouseButton::*;
        Self {
            move_forward:  vec![UserBinding::Key(KeyW), UserBinding::Key(ArrowUp)],
            move_backward: vec![UserBinding::Key(KeyS), UserBinding::Key(ArrowDown)],
            turn_left:     vec![UserBinding::Key(KeyA), UserBinding::Key(ArrowLeft)],
            turn_right:    vec![UserBinding::Key(KeyD), UserBinding::Key(ArrowRight)],
            strafe_left:   vec![UserBinding::Key(KeyQ)],
            strafe_right:  vec![UserBinding::Key(KeyE)],
            jump:          vec![UserBinding::Key(Space)],
            mouse_look:    vec![UserBinding::Mouse(Right)],
            left_mouse:    vec![UserBinding::Mouse(Left)],
            auto_run:      vec![UserBinding::Key(NumLock)],
            sprint:        vec![],
            gamepad_jump:   vec![UserBinding::Gamepad(Gp::South)],
            gamepad_sprint: vec![UserBinding::Gamepad(Gp::LeftThumb)],
            zoom_in:    vec![UserBinding::Mouse(Other(1))],  // scroll up; verify exact Bevy variant
            zoom_out:   vec![UserBinding::Mouse(Other(2))],  // scroll down; verify exact Bevy variant
            zoom_speed: 2.0,
            mouse_sensitivity:   0.003,
            gamepad_sensitivity: 2.5,
            kb_turn_speed:       std::f32::consts::PI,
        }
    }
}

use bevy_enhanced_input::prelude::*;

use crate::{
    actions::*,
    bindings::MmoBindings,
    MmoMovementContext,

/// Despawns all action+binding children on every MmoMovementContext entity,
/// then respawns them from the current MmoBindings resource.
/// Runs on startup and whenever MmoBindings is mutated (runtime remapping).
pub fn rebuild_bindings(
    mut commands: Commands,
    bindings: Res<MmoBindings>,
    context_query: Query<Entity, With<MmoMovementContext>>,
    children_query: Query<&Children>,
) {
    if !bindings.is_changed() && !bindings.is_added() {
        return;
    }

    for ctx_entity in context_query.iter() {
        // Despawn existing action subtree
        if let Ok(children) = children_query.get(ctx_entity) {
            for &child in children.iter() {
                commands.entity(child).despawn_recursive();
            }
        }

        // Respawn actions with updated bindings.
        // bevy_enhanced_input 0.26 — verify the exact relationship API.
        // The actions! macro is static; for dynamic bindings we spawn manually.
        // Each action entity is a child of the context entity; each binding
        // entity is a child of its action entity.
        spawn_actions(&mut commands, ctx_entity, &bindings);
    }
}

fn spawn_actions(commands: &mut Commands, ctx: Entity, b: &MmoBindings) {
    commands.entity(ctx).with_children(|ctx_children| {
        spawn_bool_action::<MoveForward>(ctx_children, &b.move_forward);
        spawn_bool_action::<MoveBackward>(ctx_children, &b.move_backward);
        spawn_bool_action::<TurnLeft>(ctx_children, &b.turn_left);
        spawn_bool_action::<TurnRight>(ctx_children, &b.turn_right);
        spawn_bool_action::<StrafeLeft>(ctx_children, &b.strafe_left);
        spawn_bool_action::<StrafeRight>(ctx_children, &b.strafe_right);
        spawn_bool_action::<Jump>(ctx_children, &[
            crate::bindings::UserBinding::Key(bevy::input::keyboard::KeyCode::Space),
        ].iter().chain(b.jump.iter()).cloned().collect::<Vec<_>>());
        spawn_bool_action::<MouseLook>(ctx_children, &b.mouse_look);
        spawn_bool_action::<LeftMouse>(ctx_children, &b.left_mouse);
        spawn_bool_action::<AutoRun>(ctx_children, &b.auto_run);
        spawn_bool_action::<Sprint>(ctx_children,
            &b.sprint.iter().chain(b.gamepad_sprint.iter()).cloned().collect::<Vec<_>>());

        // Jump also gets gamepad button
        spawn_bool_action_extra::<Jump>(ctx_children, &b.gamepad_jump);

        // Vec2 actions — hardcoded axes, no UserBinding
        ctx_children.spawn_empty().with_children(|a| {
            a.spawn(Binding::MouseMotion);
        }).insert(Action::<MouseDelta>::new());

        ctx_children.spawn_empty().with_children(|a| {
            a.spawn(Binding::GamepadAxis {

    parent: &mut ChildSpawnerCommands,
    user_bindings: &[crate::bindings::UserBinding],
) {

use bevy::prelude::*;
use bevy_enhanced_input::prelude::*;

use crate::{
    actions::*,
    bindings::MmoBindings,
    state::{InputSource, MmoMovementState},
    MmoMovementMask, MmoMovementContext,
};

pub fn update_state(
    bindings: Res<MmoBindings>,
    time: Res<Time>,
    mut context_q: Query<(&mut MmoMovementState, &MmoMovementMask), With<MmoMovementContext>>,
    // Pull-style: for single local player, Single<> is ergonomic.
    // If bevy 0.19 Single API differs, replace with Query<...>.single().
    move_fwd:      Single<&Action<MoveForward>>,
    move_bwd:      Single<&Action<MoveBackward>>,
    turn_left:     Single<&Action<TurnLeft>>,
    turn_right:    Single<&Action<TurnRight>>,
    strafe_left:   Single<&Action<StrafeLeft>>,
    strafe_right:  Single<&Action<StrafeRight>>,
    jump:          Single<(&Action<Jump>, &ActionState)>,
    mouse_look:    Single<&Action<MouseLook>>,
    left_mouse:    Single<&Action<LeftMouse>>,
    auto_run_ev:   Single<&ActionEvents, With<Action<AutoRun>>>,
    mouse_delta:   Single<&Action<MouseDelta>>,
    gamepad_move:  Single<&Action<GamepadMove>>,
    gamepad_cam:   Single<&Action<GamepadCamera>>,
    sprint_action: Single<(&Action<Sprint>, &ActionState)>,
) {
    let dt = time.delta_secs();

    let fwd_held   = **move_fwd;
    let bwd_held   = **move_bwd;
    let turn_l     = **turn_left;
    let turn_r     = **turn_right;
    let strafe_l   = **strafe_left;
    let strafe_r   = **strafe_right;
    let mouse_l    = **mouse_look;
    let left_m     = **left_mouse;
    let m_delta    = **mouse_delta;
    let gp_move    = **gamepad_move;
    let gp_cam     = **gamepad_cam;

    let (jump_action, jump_state) = *jump;
    let jump_fired = *jump_state == ActionState::Fired && jump_action.is_started();

    let (sprint_action, sprint_state) = *sprint_action;
    let sprint_fired = *sprint_state == ActionState::Fired && sprint_action.is_started();

    let auto_run_just_started = auto_run_ev.contains(ActionEvents::STARTED);

    let is_gamepad = gp_move.length_squared() > 0.01 || gp_cam.length_squared() > 0.01;

    for (mut state, mask) in context_q.iter_mut() {
        // Toggle auto_run on key-just-pressed
        if auto_run_just_started {
            state.auto_run = !state.auto_run;
        }

        let is_mouse_look = mouse_l || is_gamepad;
        state.is_mouse_look = is_mouse_look;
        state.input_source = if is_gamepad { InputSource::Gamepad } else { InputSource::KeyboardMouse };

        // --- Camera delta (never masked) ---
        let cam_delta = if is_gamepad {
            gp_cam * bindings.gamepad_sensitivity * dt
        } else {
            m_delta * bindings.mouse_sensitivity
        };
        state.camera_delta = cam_delta;

        // --- Movement intent (camera-relative) ---
        let mut intent = Vec2::ZERO;
        let mut yaw = 0.0f32;

        if is_gamepad {
            // FFXIV-style: left stick is always camera-relative strafe/forward
            intent.x += gp_move.x;
            intent.y += gp_move.y;
            // Right stick drives yaw (and camera via camera_delta above)
            yaw += cam_delta.x;
        } else {
            // Keyboard forward/backward
            if fwd_held { intent.y += 1.0; }
            if bwd_held { intent.y -= 1.0; }

            // Q/E always strafe
            if strafe_l { intent.x -= 1.0; }
            if strafe_r { intent.x += 1.0; }

            if is_mouse_look {
                // RMB held: A/D strafe, mouse drives yaw
                if turn_l { intent.x -= 1.0; }
                if turn_r { intent.x += 1.0; }
                yaw += cam_delta.x;
            } else {
                // Keyboard-only: A/D turn
                if turn_l { yaw -= bindings.kb_turn_speed * dt; }
                if turn_r { yaw += bindings.kb_turn_speed * dt; }
            }

            // Both mouse buttons held → force forward
            if left_m && mouse_l { intent.y = intent.y.max(1.0); }
        }

        // Auto-run ensures minimum forward motion before masking
        if state.auto_run { intent.y = intent.y.max(1.0); }

        // Clamp analog (gamepad) to unit circle
        if intent.length() > 1.0 { intent = intent.normalize(); }

        // --- Apply MmoMovementMask ---
        if !mask.contains(MmoMovementMask::MOVEMENT) { intent = Vec2::ZERO; }
        if !mask.contains(MmoMovementMask::TURNING)  { yaw = 0.0; }
        // camera_delta is intentionally NOT masked

        let jump_out   = jump_fired   && mask.contains(MmoMovementMask::JUMPING);
        let sprint_out = sprint_fired && mask.contains(MmoMovementMask::JUMPING);
        // vertical_intent: currently no keyboard binding; swimming/flying hookup is game code
        let vert = if !mask.contains(MmoMovementMask::VERTICAL) { 0.0 } else { state.vertical_intent };

        state.move_intent    = intent;
        state.yaw_delta      = yaw;
        state.jump           = jump_out;
        state.sprint         = sprint_out;
        state.vertical_intent = vert;
        state.tick           += 1;
    }
}

// src/tnua.rs  (compiled only with feature = "tnua")
use bevy::prelude::*;
use bevy_tnua::prelude::*;

use crate::{MmoMovementContext, MmoMovementParams, MmoMovementState};

/// Optional camera orientation written by the mmo_camera crate.
/// If absent, falls back to the entity's own Transform forward direction.
#[derive(Component, Reflect, Default, Clone, Copy)]
#[reflect(Component)]
pub struct MmoCameraOrientation {
    /// World-space yaw in radians (0 = +Z forward).
    pub yaw: f32,
    /// Pitch in radians (clamped by mmo_camera).
    pub pitch: f32,
    /// Current zoom distance (informational).
    pub distance: f32,
}

/// Add this system to your app when using the `tnua` feature.
///
/// ```rust
/// use mmo_input::tnua::drive_walk_basis;
/// app.add_systems(Update, drive_walk_basis::<MyActions>.after(mmo_input::MmoSystems::UpdateState));
/// ```
///
/// `S` must match the type parameter of your `TnuaController<S>`.
pub fn drive_walk_basis<S: Send + Sync + 'static>(
    mut query: Query<(
        &MmoMovementState,
        &MmoMovementParams,
        &mut TnuaController<S>,
        Option<&MmoCameraOrientation>,
        &Transform,
    ), With<MmoMovementContext>>,
) {
    for (state, params, mut controller, cam_orientation, transform) in query.iter_mut() {
        // Determine camera yaw: prefer mmo_camera's orientation, fall back to entity facing.
        let camera_yaw = cam_orientation
            .map(|o| o.yaw)
            .unwrap_or_else(|| {
                // Extract yaw from the entity's current Transform
                let (_, yaw, _) = transform.rotation.to_euler(EulerRot::YXZ);
                yaw
            });

        // Rotate camera-relative move_intent (Vec2) into world-space Vec3.
        // camera_yaw=0 → +Z forward, positive yaw → clockwise when viewed from above.
        let sin_y = camera_yaw.sin();
        let cos_y = camera_yaw.cos();
        let local = state.move_intent;
        let world_dir = Vec3::new(
            local.x * cos_y + local.y * sin_y,
            0.0,
            -local.x * sin_y + local.y * cos_y,
        );

        let effective_speed = params.walk_speed * params.speed_multiplier;
        let desired_motion = world_dir * effective_speed;

        // desired_forward: face movement direction when moving; keep current facing when still.
        let desired_forward = Dir3::new(world_dir).ok();

        // Set walk basis every frame — Tnua requires this.
        // TnuaBuiltinWalkConfig (speed, float_height, etc.) must be added as a component
        // on the player entity separately (see mmo_input docs). mmo_input only drives the
        // per-frame TnuaBuiltinWalk input struct.
        controller.basis = TnuaBuiltinWalk {
            desired_motion,
            desired_forward,
        };
    }
}
